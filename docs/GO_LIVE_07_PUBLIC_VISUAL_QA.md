# GO-LIVE 07 — Public Visual QA Checklist

Manual responsive checklist for the CloneStore public funnel.
Run before each public launch candidate.

---

## Checklist per page

For each page, verify at every breakpoint:

- [ ] No horizontal overflow (no side-scroll)
- [ ] Primary CTA visible above the fold
- [ ] Text contrast readable (no light-on-light)
- [ ] Buttons tap-friendly (min 44px hit area)
- [ ] No text truncated or cut off
- [ ] Cards aligned — no broken grid
- [ ] Header/nav usable (hamburger or rail)
- [ ] Footer / legal mention accessible
- [ ] Demo link (/demo/pierre) reachable
- [ ] No broken images or missing icons
