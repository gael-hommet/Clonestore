\# Supabase migrations (manual)



Chaque fichier .sql ici correspond à une modification faite dans Supabase.

Règle : dès qu'on fait une modif SQL dans Supabase, on crée un fichier ici.



\## Appliquer une migration (manual)

\- Aller dans Supabase > SQL Editor

\- Coller le contenu du fichier .sql

\- Run



\## Ordre

Les migrations sont nommées avec la date, donc elles s'appliquent dans l'ordre chronologique.
